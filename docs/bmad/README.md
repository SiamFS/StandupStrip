# 📚 BMad Project Documentation Suite

This directory contains the comprehensive documentation generated via the **BMad Method** (Agentic Coding Framework). These artifacts trace the full lifecycle of the **StandUpStrip** project, from initial ideation to final verification.

## 📂 Navigation Guide

### 1. 🧠 Ideation & Planning
*   **[Brainstorming Phase](brainstorming-session-results.md)**: The initial session capturing the spark and ideas for the project.
*   **[Project Brief](project-brief.md)**: High-level overview defining the scope, goals, and MVP.
*   **[Brainstorming Output](brainstorming-output.md)**: Detailed structured output of the brainstorming session.

### 2. 📋 Core Specifications (Sharded)
These documents are broken down ("sharded") into granular files for better AI context management.

*   **[Product Requirements (PRD)](prd/index.md)**: Detailed functional and non-functional requirements, organized by Epic.
    *   *See `prd/` folder for individual epic requirements.*
*   **[Architecture Document](architecture/index.md)**: Technical design, data models, API specs, and tech stack.
    *   *See `architecture/` folder for schema definions.*
*   **[UI/UX Specification](front-end-spec/index.md)**: Design system, user flows, and component libraries.
    *   *See `front-end-spec/` folder for visual specs.*

### 3. ✅ Implementation & Verification
*   **[User Stories](../stories)**: The executable backlog. Each story file in `docs/stories/` contains:
    *   **Requirements** (Drafted by Scrum Master)
    *   **Implementation Records** (Filled by Developer)
    *   **QA Certification** (Verified by QA Architect)

### 4. 🛡️ Validation Reports
*   **[PM Checklist](pm-checklist-validation.md)**: Product Manager's sign-off on the PRD.
*   **[Architect Checklist](architect-checklist-validation.md)**: Technical feasibility verification.
*   **[PO Master Validation](po-master-validation.md)**: Final "Ready for Dev" certification.

## 🔗 Traceability Map

To trace a feature from concept to code:
1.  Find the feature idea in **[Brainstorming](brainstorming-session-results.md)**.
2.  See its definition in **[PRD](prd/requirements.md)**.
3.  Check its technical design in **[Architecture](architecture/index.md)**.
4.  View the implemented task in **[User Stories](../stories)** (e.g., look for `1.1.user-registration.md`).
