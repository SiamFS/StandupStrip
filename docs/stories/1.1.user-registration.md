# Story 1.1: User Registration

## Status
Done

## Story
**As a** new user,
**I want** to register with my email and password,
**so that** I can create an account and access the application.

## Acceptance Criteria
1. Registration form accepts email (unique validation) and password (min 8 characters)
2. Password is hashed with bcrypt before storage
3. User record is created with `verified=false` status
4. Verification email is sent with unique token (24-hour expiry)
5. User cannot log in until email is verified
6. Duplicate email registration returns 409 Conflict error

## Dev Notes
**Technical Context:**
- **Backend:** Spring Boot 4 + Java 21
- **Database:** PostgreSQL (Table: `users`)
- **Security:** Spring Security 6 (BCryptPasswordEncoder)
- **Frontend:** Next.js 15 (App Router)
- **Validation:** Jakarta Validation (Backend) + Zod (Frontend)

**Data Models [Source: architecture/data-models.md]:**
- `User`: id (Long), email (String, Unique), password_hash (String), verified (Boolean)

**API Specification [Source: architecture/rest-api-spec.md]:**
- `POST /auth/register`:
  - Body: `{ "email": "...", "password": "...", "name": "..." }`
  - Responses: 201 Created, 400 Bad Request, 409 Conflict

**Security Rules [Source: architecture/security.md]:**
- Input validation required (JSR 380)
- Password must be hashed (BCrypt strength 10)
- Secrets (SMTP creds) must use environment variables

**Project Structure:**
- Backend: `src/main/java/com/standupstrip/backend/`
  - `auth/` (Controller, Service)
  - `user/` (Entity, Repository)
- Frontend: `src/app/register/page.tsx`

## Testing
**Testing Standards [Source: architecture/tech-stack.md]:**
- **Backend:** JUnit 5 for unit tests, Spring Boot Test for integration.
- **Frontend:** Jest/React Testing Library (optional for this story if manual testing covers it, but recommended).
- **Core Requirement:** Ensure `password_hash` is never returned in API responses.
